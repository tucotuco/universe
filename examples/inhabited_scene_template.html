Model boundaries

This prototype integrates existing Domain objects. Its encounter uses a local metre frame registered to the regional x/y map, and includes only sampled terrain-aware visibility and a simplified light-detection proxy, not full optical vision, actual sunset, sound, settlement populations or physical locomotion. Statistical composition is realized only when a successful observation needs it. Uncertainty intervals are heuristic, not Bayesian confidence bounds. Export uses journal replay, not serializing Python objects.
