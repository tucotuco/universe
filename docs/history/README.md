# Historical documentation

This directory preserves selected older planning, decision, checkpoint, and
repository records that were moved from earlier root-level locations. These
files document their original scope and date; their presence does not make old
proposals, mechanics, test counts, or checkpoints current authority.

For current simulation rules, use the [Encounter documentation package](../encounters/README.md):
revision 61 baseline with revision 62 and 63 supplements. For present
implementation status, use [`TASKS.md`](../../TASKS.md), active topic tasks,
current source/tests, and later explicit user decisions. Private archive
payloads remain referenced by the portable [historical archive index](historical-evidence-archive-index.md)
and are not runtime dependencies or GitHub backups.

The older Universe 6 → 7 handoff contains a machine-specific checkout path in
its original local Git history. It is not copied into this directory or
included in the Universe 8 handoffs; it must be sanitized through a separately
authorized unpublished-history correction before that history can be pushed.
