# Revision 68 — simultaneous Wrest custody and willing Touch

**Adopted ruling (U-ARENA-018D continuation, 12 November 2026):**

## Simultaneous successful Wrest claims

When multiple challengers successfully Wrest the same Object from its current holder at the same resolution boundary, **every successful challenger holds that one same Object after the common state commitment**, and the prior holder no longer holds it. Do not select one successful challenger as the winner, reroll the contests, or duplicate the Object. Evaluate each contest independently from the shared pre-action snapshot. Stage the shared custody result and receipt updates atomically, preserving the single native Object identity, deterministic RNG history, observation boundaries, rollback and Save/Load behavior.

This ruling does not define a later Wrest contest between any of the Beings who jointly hold the Object. Such a subsequent contest remains unsupported pending a separate rule.

## Willing Touch during another Action

Remove the abstract Action-capacity test from the willing-Touch exception. A willing Touch attempted while the actor is performing another Action is permitted without requiring a declared Multiple-action program, unless an actual condition or circumstance precludes it (for example, paralysis). Preserve the remaining adopted Touch requirements, including participant willingness, reach and the applicable Dexterity checks for actor/recipient motion. This exception adds no general Action-capacity mechanism and does not alter restrictions on unwilling Touch.
