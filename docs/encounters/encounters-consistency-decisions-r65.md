# Encounter consistency decisions — revision 65

## Generated Arena: unobstructed initial perception

**Adopted for the bounded generated Arena scenario.** At Encounter initialization, each participating Being perceives every other generated Being and every extant, realized physical Object when the authored local environment is explicitly unobstructed. This applies at native time zero, without a Spot roll, distance limit, or same-hex discovery condition. The observer's own duplicate self-awareness is omitted.

This scenario rule records observer-owned evidence. It does not make the player omniscient about private Actions, random state, Generator source/provenance, uninstantiated possessions, or hidden Being attributes. Current positions and ordinary Object/Being names and types are perceptible. The generated Arena has no modeled obstructions; if terrain or occlusion is later introduced, visibility must be evaluated using an adopted native contract and unknown geometry must fail closed.

The decision supersedes any earlier limited ground-Object discovery proposal for this Arena. It does not change general world perception or the geometry-dependent native Spot resolver. Perception and access remain separate: revision 64's same-hex free-ground-Object condition still controls Pick up eligibility. Seeing a distant Object neither grants possession nor permits pickup.

## Implementation and boundaries

The generated Arena seeds independent observer ledgers inside private candidate creation. At later committed Encounter boundaries, changed visible positions and custody states are staged with native publication from the shared post-movement snapshot. A carried Object retains historical evidence but no longer has a ground position. Browser references are opaque observer-scoped handles, and native Object identity is accepted only after the server resolves a current ledger entry and revalidates native custody and same-hex access.

This revision does not adopt body geometry, collision, line-of-sight physics, concealment, weapon readiness, or a default equipment distribution. Physical collision remains unadjudicated.
