# Encounters — check inventory, Revision 22 review status

The original **70-row procedural inventory** from Revision 21 is preserved as the historical Markdown inventory and CSV. Those rows describe the *pre-decision* draft and contain superseded proposed alternatives.

## Generic rules now adopted

- **Difficulty check:** d20 against stated DC including integer DC adjustments. No named skill is required. Spotting and Hearing are DC15 difficulty checks, not skills.
- **Skill check:** named skill, d20 + skill level + governing ability bonus + stated modifiers vs DC; at skill level zero the preexisting 3d6 individual roll-under ability fallback applies unless the action prohibits untrained use.
- **Ability check:** roll-under specified Nd6 against an ability score.
- **Ability contest:** both roll 3d6 + applicable ability bonus + situational modifiers, with no automatic skill-level modifier; high wins, ties preserve status quo.
- **Opposed skill check:** both roll 3d6 + named skill level + governing ability bonus + allowed modifiers, high wins; ties preserve status quo. Skill level zero adds zero and does not trigger the individual roll-under fallback.
- **Attack roll:** existing d20 against attack DC with strategy allocation; do not double-count underlying skill.
- **Opposed attack/defense roll:** existing two-d20 procedure in Grab, Disarm, unwilling Touch. Not the generic opposed skill check.
- **Saving throw:** separate d20 against save DC.
