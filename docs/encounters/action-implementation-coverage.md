## Exact cross-cutting limits

- Shield timing table `ST` is defined in the Shields Table legend as the swing-attack timing. Don/Remove rates are therefore recoverable for an identified shield type (`ST × 5`, `ST × 2`); that timing fact alone does not supply an equipment transition adapter.
- Don/Remove still need a native scheduled custody/hand transition, interruption/rollback, player controls, state receipts and fresh-process checkpoint coverage. A held/grounded shield cannot protect unless the native equipment state says it is being borne. Tower shield restrictions are in r61. An explicit authored forearm buckler remains the only currently represented forearm attachment.
- Quick-draw has no integer-second Action boundary by adopted r69; do not schedule a fake zero-duration Action. Generic Ready Object retrieval has referee-adjudicated variable time. General magical saves, generic projectile ammunition, arbitrary body geometry, acoustic propagation, and force-to-newton calibration are absent.
- The passive-shield rule grants protection to shield-size attacks per round and requires the bearer to decide which attacks beyond that capacity are protected. The Arena's current per-attack randomized shield choice is not evidence of this allocation rule; resolve the capacity/decision contract before claiming that variant complete.

## Remaining cluster order

1. Equipment state transitions and shield protection allocation; exceptional Quick-draw only after the integer-boundary semantics are adopted.
2. Ranged Shoot / general Throw / Deflect: ammunition, object profiles and collision facts.
3. Forced displacement and Pull/Bull Rush/Charge/Overrun path continuations.
4. Grappling, physical/object custody and later co-holder contests.
5. Advanced weapon, magic and Object variants with explicit data.
6. Deliberate/incidental discovery, acoustic and multiple-candidate perception.
7. Cross-cutting fatigue/exertion, persistence coverage, and Player-vs-Player gate audit.
