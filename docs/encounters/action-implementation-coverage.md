## Exact cross-cutting limits

- Shield timing table `ST` is defined in the Shields Table legend as the swing-attack timing. Don/Remove use `ST × 5` and `ST × 2`. The native transition reserves the selected hand and the same shield identity, evaluates from the common snapshot, and publishes the hand/weapons change atomically. A carried but unborne shield cannot protect; removal leaves it in the same carried custody because the adopted Action does not direct an object drop. An explicit authored forearm buckler remains a distinct attachment fact and is not generalized.
- Tower shields cannot be Don actions or borne as ordinary shields. Revision 61 permits planting one for cover, but the Arena lacks an adopted ground placement/cover geometry transition, so this route is refused rather than inferred.
- Passive-shield allocation remains blocked at the simultaneous-over-capacity edge. The r61 Shields text requires the bearer to choose among excess attacks before outcomes. The general Action-information rule says a combatant cannot know another's Action choice in the same second and defense Choices are limited to what the combatant can perceive. Native snapshot evaluation has no defender-owned allocation record; current implementation refuses an over-capacity batch before allocating any attack or RNG. It does not pick by declaration order, hidden outcome, or AI referee chronology. A resolution rule is needed for what the defender is permitted to see and when to make that allocation.
- Quick-draw has no integer-second Action boundary by adopted r69; do not schedule a fake zero-duration Action. Generic Ready Object retrieval has referee-adjudicated variable time. General magical saves, generic projectile ammunition, arbitrary body geometry, acoustic propagation, and force-to-newton calibration are absent.
- The legacy Arena damage path's random shield selection is not evidence that the adopted per-round attack-allocation choice has been implemented.

## Remaining cluster order

1. Armor donning/removal (part composition, fit, partial-donning hit die), passive shield-size allocation, and tower shield set-down/cover geometry; exceptional Quick-draw only after integer-boundary semantics are adopted.
2. Ranged Shoot / general Throw / Deflect: ammunition, object profiles and collision facts.
3. Forced displacement and Pull/Bull Rush/Charge/Overrun path continuations.
4. Grappling, physical/object custody and later co-holder contests.
5. Advanced weapon, magic and Object variants with explicit data.
6. Deliberate/incidental discovery, acoustic and multiple-candidate perception.
7. Cross-cutting fatigue/exertion, persistence coverage, and Player-vs-Player gate audit.
