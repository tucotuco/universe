# Resolution on demand, Groups, Attention and relationships

Back to [TASKS.md](../../TASKS.md).

## Completed bounded demonstrations

- `StatisticalGroup(ObjectInstance)` is a population-specific prototype, not a general Group ontology. Trusted world code can select one already-counted adult and atomically publish its realization while conserving Group totals.
- A supported successful Spot can record exact aggregate Group count evidence for one observer; it does not expose unresolved slot identifiers, individual identity or position.
- The 5E2S adapter accepts only one eligible unfamiliar participating Being; zero or several candidates are refused. It is an experiment, not general Agent Attention or category-directed Spot.
- The 5E2U example connects Group count 28, independent trusted-world selection, next-boundary eligibility, later discovery and Awareness, then a native Thrust. No Group observation automatically triggers realization.
- Optional geometry supports a later ordinary Spot without changing Spot duration/DC/no-XP rules. Realization does not grant Awareness.

## ACTIVE: U-REL-001

The D1 design/source audit and D2 FamilyGroup contract are complete; both are proposals, and there is no adopted family model or production implementation authorization. D2's leading design candidate is a first-class world-level `FamilyGroup`, distinct from population Groups, household/social links and Being instantiation. It compares the competing ontology and resolution scopes in [`family-generation-u-rel-001-d2-contract.md`](../design/family-generation-u-rel-001-d2-contract.md); D1's implementation evidence remains in [`family-generation-u-rel-001-audit.md`](../design/family-generation-u-rel-001-audit.md). The next proof should be world-only and independent of Observation or Belief. Before implementation, resolve the approval questions in D2, especially family ontology, reproductive parent roles, chronology, scoped completeness, stable identity and non-Encounter publication.

The current Being model has no age/date-of-birth or relationship graph. `StatisticalGroup` has stable latent slot IDs and aggregate counts, but child Being realization is unsupported. The audited transaction has one typed adult-realization operation, not a general relationship-write operation. D1's edge-only B proposal is an engineering primitive, not a FamilyGroup or full-offspring API; D2 gates it behind approved role/time semantics and proposes unresolved/complete FamilyGroup cases separately. Neither is a rule decision. World generation changes no observer knowledge.

### Open archival prerequisite: U-ARC-001

Historical sources remain untrusted and are not runtime dependencies. Before adopting their distributions or formats, decode only selected formats safely and establish provenance and rights. The 5E3H archive index and static U-ARC-001 assessment locate material but do not resolve those questions. Do not execute archived code or bulk-import its data.
