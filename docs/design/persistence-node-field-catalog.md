# Persistence node field catalog

> Diagnostic artifact for U-PER-SCALE-001. It records the exact current generated-Arena node-type/field contract and a two-boundary sample; it does not authorize or implement persistence changes. The named `docs/assignments/U-PER-SCALE-001-EXACT-FIELD-AUDIT.md` was not present in the checkout at audit time, so this audit follows the exact scope in the user request.

## Schema authority and coverage

- Arena native type allowlist: `src/arena_native_snapshot.py` `_ARENA_TAGS`; native schema `universe.generated-arena-native-state/5`, compact inventory `universe.generated-arena-compact-inventory/1`.
- Portable layer: save `/12`, archive `/3`, resumable snapshot `/1`, immutable-definition table `/1`, history segment `/2`.
- The Arena allowlist contains 109 graph tags: 104 typed native tags plus five structural containers (`ordered-map`, `list`, `tuple`, `set`, `frozenset`). Each typed node is checked against `checkpoint_fields.FIELD_ADAPTERS` for allowed and required properties. The shared field registry has 152 typed adapters; 48 are excluded by the Arena allowlist and cannot appear in a current Arena save. Those excluded tags are listed after the complete Arena table.
- Field lists below are alphabetized for display. “Schema allowed” includes optional fields; “Schema required” is the subset required by strict current-schema capture/restore. “Present” lists fields found in the reassembled native graph for that saved Encounter; history/definition fields are included after strict archive decode.

## Limits and interpretation

- This is one generated two-Being specimen with one native Run resolution and one quiet commit, not a universal size curve. It measures property-level change and graph identity reuse, not a policy for deleting or compacting any field.

- `decode()` strictly validates and reassembles snapshot, immutable definitions and history before this comparison. The graph-row diffs compare the exact restored native inventory; member metrics separately show where the archive stores each category.
- No code, persistence behavior, safety limits, save fixtures, user save files or staged unrelated paths were changed for this audit.
