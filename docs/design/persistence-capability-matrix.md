# Native persistence capability matrix

> Source audit for the revised U-PER-SCALE-001 full native-persistence capability. This is a live-code coverage inventory, not a completion claim. `Arena /12` means the type is admitted by the current generated-Arena checkpoint field gate; it does not imply Arena-independent support. `native_graph_snapshot` uses the closed 157-type field registry and restores selected action, movement, combat, history, Group and observer families; `native_history/9` adds an explicit, validated availability marker for the exact pre-first-commit scheduler/Choice projection to the `/8` passive Arena observer-knowledge and earlier fact stream. The supported closure remains incomplete and duplicate receipt/Target history remains in Saves. Rows are derived from the live closed field registry and checked against the current `/12` allowlist.

## Current production boundary

- Native closed-field catalog: 157 types in `src/checkpoint_fields.py` (`FIELD_ADAPTERS`).
- Executable `checkpoint_inventory._TYPES` now includes the same 157 reviewed types. `test_executable_native_type_registry_matches_all_reviewed_field_adapters` prevents type/field-registry drift; this admits the four previously omitted typed records but does not imply semantic closure or restoration readiness.
- Current production `/12` snapshot admits 104 domain types plus five structural container types via the compatibility shim `src/arena_native_snapshot.py` (`_ARENA_TAGS`); its production capture still requires a generated Arena and Arena-owned/exclusive Encounter RNG cursor.
- `/12` persistence contract is currently rooted in `src/arena_persistence.py` and `src/arena_history_segments.py`; restoration reassembles the graph and calls `arena_native_snapshot.restore()`, which binds Arena-specific progression/receipts. It is not a general native persistence API.
- `src/checkpoint_inventory.py` still advertises a non-ready diagnostic candidate; `CheckpointCandidate.require_complete()` rejects. Native Save uses explicit closed-field capture, `src/checkpoint_adapters.py` owner recipes, strict `src/native_graph_snapshot.py` restore, and the authenticated `src/native_history.py` recorder/query path. `src/native_persistence.py` reads accepted generated-Arena `/10`–`/12` archives through strict legacy decode plus native graph restore. With an explicit pristine-start selection of native transactional mode, `/10`–`/11` files now export to native format, strict-load and continue through a legal first native Choice; generated `/12` first-Choice state also has native export/load/canonical-resave evidence. No Action is synthesized during migration. Only tested family closures may be treated as supported; all-family historical parity, crash-recoverable history journaling and production Save/Load cutover remain open.
- “Not admitted” below means no current `/12` capture/restore evidence; no inference that the native runtime type is impossible to reach. This matrix must be upgraded with per-scenario tests as each general native family is implemented.
