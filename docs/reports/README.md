# Engineering reports

Codex writes an assignment's report here while implementation is active or while the report awaits review. After ChatGPT reviews and accepts a report, move it with `git mv` to [`archive/`](archive/), update maintained references, and include the move in an audited local documentation commit. See [`docs/process/DEVELOPMENT-PROCESS.md`](../process/DEVELOPMENT-PROCESS.md) for the permanent workflow.

The one-time historical sweep on 2026-11-13 moved all 95 Markdown engineering reports previously present directly in this directory. The `.patch` file remains here because it is a proposed patch, not an engineering report.
