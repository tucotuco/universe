# Assignments

Place an authorized, unfinished assignment in this directory. `TASKS.md` is the canonical statement of current status and priority; archived assignment files are historical records, not authorization to resume work.

After ChatGPT confirms an assignment has met its acceptance criteria, use `git mv` to move it into [`archive/`](archive/README.md), update maintained references, and include the move in an audited local documentation commit. Preserve untracked supplied assignments and inspect them before staging. See [`docs/process/DEVELOPMENT-PROCESS.md`](../process/DEVELOPMENT-PROCESS.md) for the permanent workflow.

The one-time historical sweep on 2026-11-13 moved all 14 assignment documents previously present directly in this directory. The unrelated `.DS_Store` and `universe-arena.json` remain in place and are not assignment documents.
